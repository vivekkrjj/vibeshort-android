YouTube feed is client-side via the official YouTube Data API v3 and YouTube IFrame Player API.
No new Supabase schema is required for the YouTube no-repeat layer in this version:
- vs_yt_seen: persistent watched YouTube IDs in localStorage.
- ytServed: current-session served IDs.
- A YouTube video is marked watched after 5 seconds of actual PLAYING or when ended.
- Feed batches are appended before the user reaches the end.
